浏览器控制台调试指南

请按F12打开开发者工具，在控制台中执行以下调试步骤：

步骤1: 检查函数是否存在

console.log('typeof generateVideo:', typeof generateVideo);

步骤2: 检查变量

console.log('generatedImageUrl:', generatedImageUrl);
console.log('sessionId:', window.inlineVersionManager?.currentSessionId);

步骤3: 手动调用函数

generateVideo();

步骤4: 检查按钮元素

const btn = document.querySelector('.video-btn');
console.log('按钮元素:', btn);
console.log('onclick属性:', btn?.onclick);
btn?.click(); // 手动触发点击
