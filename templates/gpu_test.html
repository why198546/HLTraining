🔍 如何验证优化效果

  1. 打开Chrome DevTools (F12)
  2. More Tools → Rendering
  3. 启用 "Layer borders" (绿色边框 = 合成层)
  4. 悬停卡片时才会看到额外的绿色边框
  5. 移开鼠标，绿色边框消失 = will-change已清理
  6. 滚动时会临时出现，停止后消失
✅ 这就是智能优化的效果！
