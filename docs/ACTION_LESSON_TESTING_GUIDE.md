## 🐞 常见问题和排查

### Canvas 绘图不工作

**症状**: 画不出线条

**排查**:
```javascript
// 在浏览器控制台运行，检查 Canvas 是否初始化
const canvas = document.getElementById('drawingCanvas');
console.log('Canvas 尺寸:', canvas.width, 'x', canvas.height);
console.log('Context 状态:', canvas.getContext('2d'));
```

**解决**:
- 清除浏览器缓存（Ctrl+Shift+Delete）
- 刷新页面（F5）
- 检查浏览器控制台是否有 JavaScript 错误

### 拖拽不响应

**症状**: 拖拽火柴人部位没有反应

**排查**:
```javascript
// 在控制台检查
document.getElementById('leftArm').addEventListener('mousedown', (e) => {
  console.log('拖拽事件触发');
});
```

**解决**:
- 确保 `mouse` 事件监听器正确绑定
- 检查 CSS `transform-origin` 属性
- 尝试双击页面重新初始化

### 生成图片失败

**症状**: 点击生成按钮后没有反应或错误

**排查**:
```javascript
// 打开浏览器网络标签，观察 /api/generate_image 请求
// 检查状态码和响应内容
```

**解决**:
- 确保后端 API 正在运行
- 检查 API 密钥配置
- 查看浏览器控制台的错误信息
- 查看后端服务器日志

### 样式显示异常

**症状**: 页面布局混乱或颜色不对

**排查**:
- 打开浏览器开发者工具（F12）
- 检查 CSS 加载情况（Network 标签）
- 检查元素样式（Elements 标签）

**解决**:
- 强制刷新（Ctrl+Shift+F5）
- 清除浏览器缓存
- 检查 CSS 文件路径是否正确

## 💡 使用建议

### 最佳体验配置

**绘图板方案**:
- 💻 设备：电脑 + 鼠标或触控笔
- 🎨 适合：有美术基础或兴趣的学生
- ⏱️ 时间：5-10 分钟完成一个设计

**拖拽编辑方案**:
- 📱 设备：任何设备（触屏体验更佳）
- 🧠 适合：编程思维、参数控制学习者
- ⏱️ 时间：2-5 分钟完成一个设计

### 教学场景

**场景 1：美术兴趣班**
```
推荐：绘图板方案
流程：
1. 让学生自由绘制火柴人动作
2. 讨论如何用词汇描述动作
3. 生成图片对比
4. 反思：AI 如何理解你的描述？
```

**场景 2：编程思维课**
```
推荐：拖拽编辑方案
流程：
1. 学生设计姿势（调整角度参数）
2. 观察参数与视觉效果的对应关系
3. 讨论：什么参数组合最协调？
4. 反思：参数化设计的优势和局限
```

**场景 3：创意综合课**
```
推荐：两个方案都体验
流程：
1. 第一部分：用绘图板自由创作
2. 第二部分：用拖拽方案精确调整
3. 对比两种方法的优缺点
4. 学生自己选择更喜欢的方式
```
