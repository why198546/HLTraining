# 松果正式课程系统

## 概述

松果正式课程系统是专为8-14岁儿童设计的AI绘画教学平台，包含15节系统化课程，分为4个模块。

## 课程结构

### 一、人像模块（4课时）

1. **第 1 课：发型**
   - 学习不同发型的特征与表现技巧
   - 特征选择：长度、类型、颜色

2. **第 2 课：脸型**
   - 掌握各种脸型的绘画要领
   - 特征选择：圆脸、方脸、瓜子脸、鹅蛋脸

3. **第 3 课：五官**
   - 细致描绘眼睛、鼻子、嘴巴等五官特征
   - 特征选择：眼睛、鼻子、嘴巴

4. **第 4 课：肤色**
   - 学习不同肤色的表现与光影处理
   - 特征选择：深色、中等、浅色

### 二、体态模块（3课时）

5. **第 5 课：体型**
   - 掌握不同体型的绘画技巧
   - 特征选择：偏瘦、正常、偏胖

6. **第 6 课：服饰**
   - 学习服装的搭配与细节刻画
   - 特征选择：风格、颜色

7. **第 7 课：饰品**
   - 学习各类饰品的表现方法
   - 特征选择：眼镜、帽子、围巾、首饰

### 三、场景模块（3课时）

8. **第 8 课：远近/透视**
   - 理解空间透视与景深关系
   - 特征选择：视角、距离

9. **第 9 课：天气**
   - 表现晴天、雨天等不同天气效果
   - 特征选择：天气、时间

10. **第 10 课：地点**
    - 绘制各种场景环境与背景
    - 特征选择：室内、室外、公园、教室、海边

### 四、综合创作模块（5课时）

11. **第 11 课：综合练习一**
    - 人像与体态的综合应用
    - 特征选择：性别、体型、服装

12. **第 12 课：综合练习二**
    - 人像与场景的结合创作
    - 特征选择：人物、场景、天气

13. **第 13 课：综合练习三**
    - 多元素的整体画面构建
    - 特征选择：人物数量、动作、环境

14. **第 14 课：AI动画**
    - 让静态作品动起来
    - 特征选择：风格

15. **第 15 课：结业作品**
    - 创作并展示个人结业作品
    - 特征选择：主题、情感

## 功能模块

### 1. 图片生成模块

- **特征检测器**：根据课程内容，预制关键特征选项
- **智能组合**：通过选择特征，自动生成提示词
- **AI生成**：调用Nano Banana API生成图片
- **儿童友好**：自动添加"卡通风格、儿童插画"等后缀

### 2. 课后小游戏模块

- **拍照上传**：上传孩子的照片
- **作品上传**：上传孩子画的作品
- **智能组合**：
  - 发型课：将画的发型应用到照片上
  - 服饰课：将画的服装应用到照片上
  - 其他课程：并排展示对比

### 3. AI点评模块

- **年龄适配**：专为8-14岁儿童设计
- **鼓励为主**：多表扬、委婉指出问题
- **具体建议**：针对课程重点给出改进方向
- **情感关怀**：使用emoji和亲切的语言

## 技术实现

### 前端

- HTML5 + CSS3 + JavaScript
- 响应式设计，支持移动端
- 特征选择器动态生成
- 实时预览和加载状态

### 后端

- Flask Blueprint架构
- 三个主要API端点：
  1. `/api/generate-image` - 图片生成
  2. `/api/combine-images` - 图片组合
  3. `/api/artwork-feedback` - 作品点评

### AI集成

- **图片生成**：Nano Banana API
- **提示词翻译**：prompt_translator模块
- **图片处理**：Pillow库
- **点评系统**：模板化点评（可扩展为AI模型）

## 配置说明

### 课程配置（courses.py）

每个课程包含以下字段：

```python
{
    'title': '第 X 课：标题',
    'desc': '课程描述',
    'section': '章节标识',
    'type': 'formal',
    'order': X,  # 顺序
    'module': '模块名称'  # 人像/体态/场景/综合创作
}
```

### 特征配置（sunguo_formal_lesson.html）

每个课程的特征选择器配置：

```javascript
'lesson_key': [
    {
        label: '标签',
        feature: '特征名',
        options: [
            { text: '显示文本', value: '提示词值' }
        ]
    }
]
```

## 扩展建议

### 短期优化

1. **AI点评增强**：集成真实的图像识别模型
2. **图片组合优化**：使用AI进行智能抠图和融合
3. **动画生成**：为第14课接入视频生成API

### 长期规划

1. **学习进度追踪**：记录每个学生的课程完成情况
2. **作品集系统**：为每个学生建立个人作品集
3. **家长端功能**：查看孩子的学习报告和作品
4. **证书系统**：完成课程后颁发电子证书

## 注意事项

1. **内容审核**：所有AI生成内容需要适合8-14岁儿童
2. **隐私保护**：上传的照片需要妥善保管，不对外展示
3. **性能优化**：图片生成可能较慢，需要良好的加载提示
4. **错误处理**：API调用失败时需要友好的错误提示
