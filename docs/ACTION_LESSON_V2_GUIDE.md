# 第 2 节课：动作 - 两个设计方案

## 概述

为了让"动作"课的教学体验更加丰富，我们设计了两个完全不同的交互方案：
- **方案 1：绘图板方案** - 自由创作式
- **方案 2：拖拽编辑方案** - 交互式参数控制

两个方案都保留了原有的文字输入方案作为备选。

---

## 📍 访问方式

### 方案选择页面
- **URL**: `/sunguo-action-chooser`
- **说明**: 显示两个方案的详细对比，用户可以选择自己喜欢的方案

### 方案 1：绘图板
- **URL**: `/sunguo-action-v1`
- **模板**: `sunguo_lesson_action_v1_canvas.html`
- **特点**:
  - 基于 HTML5 Canvas 的自由绘图
  - 支持笔画、橡皮、颜色选择
  - 6 种预设火柴人动作（跑步、跳跃、挥手、跳舞、坐着、思考）
  - 12 个动作关键词可选
  - 完整的提示词生成和图片生成流程

### 方案 2：拖拽编辑
- **URL**: `/sunguo-action-v2`
- **模板**: `sunguo_lesson_action_v2_puppet.html`
- **特点**:
  - 可拖拽的火柴人各部位（手臂、腿）
  - 实时角度显示和参数控制
  - 6 种预设姿势一键应用
  - 随机生成有趣姿势
  - 8 个手势选项

### 原始方案：文字输入
- **URL**: `/sunguo-class/action`
- **说明**: 保持不变，仍然支持手动输入或语音输入提示词

## 🎨 方案 1：绘图板方案

### 功能模块

#### 1. 绘图区域
```
左侧：Canvas 绘图板（400x500px）
- 模式：自由绘制、橡皮擦、清空
- 笔色选择：支持任意颜色
- 背景：浅绿色渐变
- 笔画设置：2px 线宽，圆角连接
```

#### 2. 预设火柴人
6 个快速开始按钮：
- 🏃 跑步：腿部张开，臂部摆动状态
- 🤸 跳跃：双臂高举，腿部收起
- 👋 挥手：一臂摆动，另一臂举起
- 💃 跳舞：身体倾斜，四肢张开
- 🪑 坐着：腿部弯曲，身体竖直
- 🤔 思考：手托脸，气泡符号

#### 3. 动作关键词
12 个可选关键词：
```
跑步、跳跃、挥手、跳舞、坐着、躺着、走路、转身、拉伸、抬头、低头、竖起大拇指
```

#### 4. 提示词生成
- 基础模板：`一个小朋友，全身，姿势自然，四肢完整，卡通插画，干净背景`
- 动态部分：所选关键词

### 核心技术

**Canvas 绘图**:
```javascript
// 初始化
ctx.fillStyle = 'white';
ctx.fillRect(0, 0, canvas.width, canvas.height);
ctx.strokeStyle = '#000000';
ctx.lineWidth = 2;
ctx.lineCap = 'round';

// 绘制火柴人
function drawRunningStickFigure(x, y) {
  // 头：圆形
  ctx.beginPath();
  ctx.arc(x, y - 60, 15, 0, Math.PI * 2);
  ctx.fill();
  
  // 身体、手臂、腿：直线
  // ...
}
```

**鼠标事件处理**:
- `mousedown`: 开始绘制
- `mousemove`: 实时绘制或擦除
- `mouseup/mouseleave`: 停止操作

## 🤖 方案 2：拖拽编辑方案

### 功能模块

#### 1. 火柴人组件
由 6 个可拖拽的部位组成：
```
- 头（圆形，固定）
- 身体（矩形，固定）
- 左臂（矩形，可旋转）
- 右臂（矩形，可旋转）
- 左腿（矩形，可旋转）
- 右腿（矩形，可旋转）
```

#### 2. 拖拽机制
```javascript
// 当拖拽一个部位时：
1. 记录起始位置和原始角度
2. 计算鼠标移动距离
3. 转换为旋转角度（限制 -90° 到 +90°）
4. 实时更新 transform: rotate()
5. 显示数字角度反馈
```

#### 3. 预设姿势
6 种一键应用的姿势配置：
```javascript
const presets = {
  running: {
    leftArm: -30,
    rightArm: 30,
    leftLeg: -45,
    rightLeg: 45
  },
  // ... 其他 5 种
}
```

#### 4. 手势选择
8 个手势选项（带 emoji）：
```
跑步、跳跃、挥手、跳舞、坐着、走路、拉伸、思考
```

#### 5. 角度显示面板
实时显示 4 个关节的角度数值：
- 左臂：0°
- 右臂：0°
- 左腿：0°
- 右腿：0°

### 核心技术

**DOM 拖拽**:
```javascript
let draggedPart = null;

element.addEventListener('mousedown', (e) => {
  draggedPart = part;
  dragStartAngle = part.angle;
});

document.addEventListener('mousemove', (e) => {
  if (draggedPart) {
    // 计算角度变化
    const angle = Math.atan2(deltaY, deltaX) * (180 / Math.PI);
    part.angle = dragStartAngle + (angle / 10);
    part.element.style.transform = `rotate(${part.angle}deg)`;
  }
});
```

**CSS 变换**:
```css
.puppet-left-arm {
  width: 80px;
  height: 20px;
  transform-origin: right center; /* 从右端旋转 */
}
```

## 🔄 用户流程

4. 选择手势分类（单选）
5. 系统自动生成提示词

## 📝 使用建议

### 什么时候选择哪个方案？

**选择绘图板方案（方案 1）如果：**
- ✅ 学生有美术兴趣或基础
- ✅ 想要完全自由的创意表达
- ✅ 用电脑/平板（配笔）操作
- ✅ 课程主题是"创意绘画"

**选择拖拽编辑方案（方案 2）如果：**
- ✅ 学生是初学者，无绘画经验
- ✅ 想要参数化、可控的设计
- ✅ 用手机或触屏设备操作
- ✅ 课程主题是"交互设计"或"编程思维"

**保留原始方案（文字输入）如果：**
- ✅ 学生不想进行视觉设计
- ✅ 希望使用语音输入
- ✅ 重点是提示词优化能力

## 🎯 教学建议

### 课堂引导

**绘图板方案：**
```
"同学们，今天我们要像艺术家一样！
拿起笔（鼠标）在画布上自由绘制一个正在做动作的火柴人。
画完后，选择最好地描述这个动作的词汇，AI 就会把你的简笔画变成漂亮的卡通人物！"
```

**拖拽编辑方案：**
```
"今天我们来设计一个火柴人娃娃的姿势！
你可以拖拽这个火柴人的手臂和腿，让它做出各种酷炫的动作。
每一个拖拽都有精确的角度数值，就像编程一样！
然后看看 AI 能把你的设计变成什么样的漂亮角色！"
```

### 评价标准

**对于绘图板方案：**
- 火柴人是否清晰可辨
- 动作是否表达明确
- 关键词选择是否恰当

**对于拖拽编辑方案：**
- 姿势是否反映了所选动作
- 各部位角度组合是否协调
- 提示词是否有创意补充

## 🐛 故障排除

### Canvas 绘图不显示
- 检查浏览器是否支持 HTML5 Canvas
- 清空浏览器缓存
- 检查 Canvas 尺寸是否合理（400x500）

### 拖拽不灵敏
- 检查 mouse 事件监听是否正确添加
- 确认 CSS `transform-origin` 设置正确
- 尝试清空浏览器缓存

### 图片生成失败
- 检查 `/api/generate_image` 端点是否可用
- 确认提示词格式正确
- 检查 API 密钥和模型配置
