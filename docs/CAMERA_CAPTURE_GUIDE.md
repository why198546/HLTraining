# 摄像头拍摄功能说明

## 功能概述
系统会根据设备类型智能选择最佳的图片拍摄方式，确保在不同设备上都能获得最佳体验。

## 三种拍摄方案

### 📱 方案1：移动设备（iOS/Android）
**检测条件：** 通过User-Agent检测到移动设备
**实现方式：** 使用HTML5的`<input capture="environment">`属性
**用户体验：**
- 点击"图片拍摄"后直接调用系统相机
- 可选择后置摄像头（environment）
- 拍摄后自动返回应用
- 图片自动压缩到1024x1024，80%质量

**优点：**
- 无需权限请求
- 系统原生相机体验
- 兼容性好（iOS/Android）

### 💻 方案2：桌面设备（支持WebRTC）
**检测条件：** 非移动设备 + 支持`navigator.mediaDevices.getUserMedia`
**实现方式：** 使用WebRTC API创建自定义摄像头对话框
**用户体验：**
- 弹出摄像头权限请求
- 显示实时视频预览窗口
- 点击"拍摄"按钮捕获当前帧
- 自动压缩后显示预览

**特性：**
- 实时视频预览
- 自定义拍摄界面
- 支持1920x1080高清拍摄
- 自动压缩到适合上传的尺寸

**摄像头对话框界面：**
```
┌─────────────────────────────┐
│  📷 拍摄图片            ✕   │
├─────────────────────────────┤
│                             │
│    [实时视频预览画面]        │
│                             │
├─────────────────────────────┤
│   [📷 拍摄]   [取消]        │
└─────────────────────────────┘
```

### 📁 方案3：不支持摄像头
**检测条件：** 非移动设备 + 不支持WebRTC
**实现方式：** 降级到普通文件选择
**用户体验：**
- 移除`capture`属性
- 打开文件选择对话框
- 可选择已有的图片文件
- 同样进行压缩处理

## 技术实现

### 设备检测
```javascript
function isMobileDevice() {
    return /Android|webOS|iPhone|iPad|iPod|BlackBerry|IEMobile|Opera Mini/i.test(navigator.userAgent);
}

function isCameraSupported() {
    return !!(navigator.mediaDevices && navigator.mediaDevices.getUserMedia);
}
```

### 智能路由
```javascript
async function captureImage() {
    if (isMobileDevice()) {
        // 方案1: 移动端 - input capture
        triggerMobileCapture();
    } else if (isCameraSupported()) {
        // 方案2: 桌面端 - WebRTC
        await openCameraDialog();
    } else {
        // 方案3: 降级 - 文件选择
        triggerFileSelect();
    }
}
```

### 图片压缩
所有方案都会进行智能压缩：
- **最大尺寸：** 1024x1024像素
- **压缩质量：** 80%（JPEG）
- **保持比例：** 自动计算最佳缩放比例
- **文件大小：** 通常从3-5MB压缩到200-500KB

## 注意事项

### 安全要求
- **桌面端WebRTC：** 必须使用HTTPS或localhost，否则无法访问摄像头
- **权限请求：** 用户首次使用时需要授予摄像头权限

### 隐私保护
- 关闭对话框时自动停止摄像头
- 不保存任何未经用户确认的图片
- 压缩在客户端完成，原图不上传

### 用户体验优化
- 移动端：直接调用系统相机，体验流畅
- 桌面端：提供实时预览，所见即所得
- 降级方案：确保所有设备都能使用

### 文件大小优化
- **压缩前：** 手机拍摄的照片通常3-5MB
- **压缩后：** 约200-500KB
- **优势：**
  - 上传速度提升80%+
  - 节省服务器存储空间
  - 减少带宽消耗
  - 提升用户体验

## 故障排查

### 问题：桌面端点击"图片拍摄"没有反应
**原因：** 可能是权限被拒绝或不支持WebRTC
**解决：**
1. 检查浏览器控制台是否有错误信息
2. 确认使用HTTPS或localhost访问
3. 检查浏览器摄像头权限设置
4. 如果都失败，会自动降级到文件选择

### 问题：移动端打开的是相册而不是相机
**原因：** 某些浏览器对`capture`属性的实现不同
**解决：** 这是正常行为，用户可以选择拍照或从相册选择

### 问题：拍摄的图片质量下降
**原因：** 为了优化上传和存储，进行了压缩
**解决：** 
- 当前压缩质量为80%，平衡了质量和大小
- 如需调整，修改`compressImage()`函数的quality参数
- 对于AI上色，1024x1024已经足够
