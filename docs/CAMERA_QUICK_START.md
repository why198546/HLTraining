# 📷 拍照功能 - 快速开始

## ✨ 新功能：松果课堂拍照上传

孩子们现在可以在松果课堂的任何课程中拍照或上传参考图片，帮助生成更形象的人物！

## 🎯 怎么使用？

### 第1步：打开课程
访问松果课堂任意课程（如人物、动作、场景等）

### 第2步：点击相机按钮
在文本输入框下方看到三个按钮，点击中间的 **📷 相机** 按钮

```
输入框下方的三个按钮：
🎤 麦克风   📷 相机（新增！）  ✨ 魔法棒
```

### 第3步：选择拍照或上传
- **拍照**：启动摄像头并拍摄参考照片
- **上传**：从设备中选择现有的图片文件

### 第4步：确认使用
预览图片后点"使用"，系统自动添加参考描述到提示词

### 第5步：继续编辑和生成
在现有描述基础上继续修改，然后点"生成图片"

## 💡 拍照小贴士

✅ **拍得好的照片：**
- 光线充足明亮
- 人物或场景在画面中心
- 背景简洁不复杂

❌ **应该避免：**
- 过暗或逆光
- 主体太小或偏离画面
- 垃圾或不适合儿童的内容

## 🤔 常见问题

**Q: 拍的照片会被上传到服务器吗？**  
A: 不会。图片完全在浏览器本地处理，只有文字描述会添加到提示词。

**Q: 支持哪些图片格式？**  
A: JPG, PNG, WebP, GIF 等常见格式都支持，最大 10MB。

**Q: 拍照时摄像头权限被拒绝了怎么办？**  
A: 查看浏览器地址栏的权限提示，点击"允许"。或在浏览器设置中永久允许。

**Q: 可以拍多张照片吗？**  
A: 可以，每次使用拍照功能都是独立的，可以多次拍照和上传。
