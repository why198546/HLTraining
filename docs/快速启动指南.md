# 🚀 快速启动指南

## 自动激活虚拟环境

项目已配置为自动激活虚拟环境，有以下几种方式：

### 方式1：VS Code集成终端（推荐）

在VS Code中打开终端，虚拟环境会自动激活。

**配置文件：** `.vscode/settings.json`
- 自动使用 `.venv\Scripts\python.exe`
- 每次打开新终端自动激活
- 显示 ✅ 虚拟环境已激活

### 方式2：手动激活脚本

如果需要手动激活，运行：

```powershell
.\activate.ps1
```

### 方式3：直接激活

```powershell
.\.venv\Scripts\Activate.ps1
```

## 启动应用

### 开发模式

```powershell
python run.py
```

**特点：**
- 热重载（代码修改自动重启）
- 调试模式
- 详细错误信息
- 适合开发和测试

### 生产模式

```powershell
# 启动服务（后台运行）
.\app.ps1 start

# 查看状态
.\app.ps1 status

# 查看日志
.\app.ps1 log

# 实时跟踪日志
.\app.ps1 log -Follow

# 停止服务
.\app.ps1 stop

# 重启服务
.\app.ps1 restart
```

**特点：**
- 后台守护进程
- 日志自动记录
- 进程管理
- 适合正式部署

## 虚拟环境说明

### 为什么使用虚拟环境？

- ✅ **隔离依赖** - 避免与系统Python冲突
- ✅ **版本控制** - 确保依赖版本一致
- ✅ **易于部署** - 复制环境更简单
- ✅ **清理方便** - 删除文件夹即可

### 虚拟环境位置

```
D:\Code\HLTraining\.venv\
├── Scripts\
│   ├── python.exe        # Python解释器
│   ├── pip.exe           # 包管理器
│   └── Activate.ps1      # 激活脚本
├── Lib\                  # 依赖库
└── pyvenv.cfg            # 配置文件
```

### 检查虚拟环境状态

```powershell
# 查看当前Python路径
Get-Command python | Select-Object Source

# 应该显示：
# D:\Code\HLTraining\.venv\Scripts\python.exe

# 查看已安装包
pip list

# 查看环境变量
echo $env:VIRTUAL_ENV
# 应该显示：D:\Code\HLTraining\.venv
```

## 故障排查

### 问题1：虚拟环境未激活

**症状：**
```
python
# 显示系统Python路径，而非 .venv\Scripts\python.exe
```

**解决：**
```powershell
# 手动激活
.\.venv\Scripts\Activate.ps1

# 或使用快捷脚本
.\activate.ps1
```

### 问题2：无法激活（权限错误）

**症状：**
```
无法加载文件 Activate.ps1，因为在此系统上禁止运行脚本
```

**解决：**
```powershell
# 以管理员身份运行PowerShell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### 问题3：依赖包丢失

**症状：**
```
ModuleNotFoundError: No module named 'flask'
```

**解决：**
```powershell
# 确保虚拟环境已激活
.\.venv\Scripts\Activate.ps1

# 重新安装依赖
pip install -r requirements.txt
```

### 问题4：VS Code终端未自动激活

**解决：**

1. 重新加载窗口：`Ctrl+Shift+P` → `Reload Window`
2. 检查 `.vscode/settings.json` 配置
3. 手动选择解释器：`Ctrl+Shift+P` → `Python: Select Interpreter`

## 最佳实践

### ✅ 推荐做法

```powershell
# 1. 打开VS Code
code .

# 2. 终端自动激活虚拟环境
# （无需手动操作）

# 3. 启动开发服务器
python run.py

# 4. 开始开发
```

### ❌ 避免做法

```powershell
# ❌ 不要直接使用系统Python
C:\Python\python.exe app.py

# ❌ 不要全局安装项目依赖
pip install flask  # 在未激活虚拟环境时

# ❌ 不要混用不同虚拟环境
```
