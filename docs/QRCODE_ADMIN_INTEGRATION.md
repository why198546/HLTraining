# 二维码管理系统 - 管理后台集成

## 功能概述

已将二维码功能完全集成到管理后台，提供全面的二维码生成和管理能力。

## 主要功能

### 1. **生成二维码** 
在管理后台即可直接生成新的二维码，无需切换页面：

- **课程类型**：体验课 / 正式课程
- **课程名称**：从配置文件中选择
- **最大使用次数**：可限制或不限制
- **有效天数**：可设置过期时间或永久有效
- **备注说明**：为二维码添加描述信息

### 2. **二维码列表管理**
查看所有已生成的二维码，每个二维码卡片显示：

- 二维码图片（可直接下载）
- 课程名称和类型
- 状态标识（有效/无效/已停用）
- 创建者和创建时间
- 过期时间
- 使用统计（已使用次数/报名人数）
- 备注信息

### 3. **使用记录查询**
点击"查看使用记录"可查看详细的扫码记录：

- 扫码用户信息
- 升级前/升级后角色
- 获得的松果币数量
- 扫码时间
- IP地址

### 4. **延期功能**
可以延长二维码的有效期：

- 输入要延长的天数
- 自动从原过期时间延长（如已过期则从当前时间开始）
- 显示新的过期时间

### 5. **失效/激活功能**
灵活控制二维码状态：

- **失效**：暂停二维码使用，学生无法扫码
- **激活**：重新启用已失效的二维码
- 不删除数据，可随时恢复

### 6. **删除功能**
永久删除不需要的二维码：

- 删除数据库记录
- 删除二维码图片文件
- 级联删除相关的报名记录
- ⚠️ 操作不可恢复，有二次确认

### 7. **统计概览**
管理页面顶部显示全局统计：

- 📊 总二维码数
- ✅ 有效二维码数
- 📈 总使用次数
- 👥 总报名人数

## 访问路径

### 管理员登录后
1. 进入管理后台 Dashboard
2. 点击"二维码管理"按钮
3. 访问路径：`/admin/qrcodes`

### 快速入口
管理后台Dashboard的"快速操作"区域已更新为：
- 管理教师
- 管理学生
- 松果币监控
- **二维码管理** ← 新增

## 用户菜单变化

### ❌ 移除的功能
- 教师下拉菜单中的"生成二维码"
- 教师下拉菜单中的"二维码列表"

## API端点

```
POST   /admin/qrcode/generate           - 生成新二维码
POST   /admin/qrcode/<id>/extend        - 延长有效期
POST   /admin/qrcode/<id>/deactivate    - 使二维码失效
POST   /admin/qrcode/<id>/activate      - 激活二维码
POST   /admin/qrcode/<id>/delete        - 删除二维码
GET    /admin/qrcode/<id>/enrollments   - 查看使用记录
```

## 权限控制

所有二维码管理功能均需要 **管理员权限** (`@admin_required`)：
- 只有管理员可以访问
- 教师无法访问（原有的教师二维码功能已移除）
- 普通用户无法访问

## 数据模型

使用现有的数据模型：
- `Course` - 二维码/课程信息
- `CourseEnrollment` - 报名/扫码记录
- 支持完整的关系查询和统计

## 使用流程

### 生成二维码
1. 在管理后台点击"二维码管理"
2. 填写生成表单（课程类型、名称、限制等）
3. 点击"生成"按钮
4. 查看生成结果和二维码图片

### 管理现有二维码
1. 在二维码列表中找到目标二维码
2. 查看其状态和统计信息
3. 根据需要执行操作：
   - 下载二维码图片
   - 查看使用记录
   - 延长有效期
   - 失效/激活
   - 删除

### 监控使用情况
1. 查看统计卡片了解整体情况
2. 点击"查看使用记录"查看详细信息
3. 了解哪些用户扫码、何时扫码、权限变化等

## 注意事项

⚠️ **删除操作不可恢复**：删除二维码会同时删除图片文件和所有相关记录
⚠️ **失效 vs 删除**：建议先使用失效功能，确认不再需要后再删除
⚠️ **延期操作**：如果二维码已过期，延期会从当前时间开始计算
⚠️ **管理员专属**：普通教师无法访问，需要管理员统一管理
