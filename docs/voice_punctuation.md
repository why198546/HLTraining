# 语音评论标点符号智能优化

## 功能说明

语音转录文本通常缺少标点符号，影响阅读体验。本功能为语音评论自动添加智能标点符号，使文本更易读。

## 工作模式

### 1. AI智能优化（推荐）
使用通义千问API进行智能标点优化，效果最佳。

**配置方法：**
在`.env`文件中添加：
```bash
DASHSCOPE_API_KEY=your_dashscope_api_key
```

**获取API Key：**
1. 访问 https://dashscope.console.aliyun.com/
2. 登录/注册阿里云账号
3. 开通DashScope服务
4. 创建API Key并复制

### 2. 简单规则优化（备用）
当API不可用时，自动降级到基于规则的标点优化。

**优化规则：**
- 在连接词后添加逗号：然后、所以、但是、而且等
- 识别疑问句并添加问号：吗、呢、怎么、为什么等
- 识别感叹句并添加感叹号：哇塞、太好了、真棒等
- 在合适位置添加句号

## 使用示例

**输入（语音转录）：**
```

```

**AI优化输出：**
```
好嘞，让我再来测试一下语音录入功能，看看效果如何。
```

**简单规则输出：**
```
好嘞让我再来测试一下语音录入功能看看效果如何。
```

## 技术实现

- **后端**: `api/text_punctuation.py`
- **集成点**: `auth/routes.py` 中的 `create_comment` 函数
- **AI模型**: 通义千问 qwen-turbo
- **备用方案**: 正则表达式规则引擎

## 性能说明

- AI优化：约0.5-2秒/次，准确率高
- 简单规则：即时，准确率中等
- 超时设置：5秒（超时自动降级）

## 注意事项

1. 仅对语音评论生效（`is_voice_comment=true`）
2. 如果文本已有标点（占比>10%），跳过优化
3. API调用失败时自动降级到简单规则
4. 优化后的文本保存到数据库，不影响原始音频
