# 课程级AI点评模板系统 - 快速开始

## 5分钟快速上手

### 对教师来说

#### 第一次使用（编辑模板）

1. 📚 **进入课程**
   - 打开任意正式课程，例如"发型设计"课程
   - 滚动到页面下方找到"模块三：AI点评作品"

2. ✏️ **点击编辑按钮**
   - 在模块三标题的右侧看到绿色的"修改模板"按钮
   - 点击打开编辑弹窗

3. 📝 **编辑内容**
   ```
   鼓励语：
   你对发型细节的观察很敏锐！
   
   评价维度1：线条精准度与蓬松感
   评价维度2：层次感与空间表现  
   评价维度3：风格特征的表现力
   ```

4. 💾 **保存修改**
   - 点击"保存修改"按钮
   - 等待成功提示"✅ 模板保存成功"

5. 🎓 **学生立即看到效果**
   - 学生下次上传作品时，会使用你的新模板
   - 点评内容将基于你设定的评估标准

---

### 对学生来说

#### 获得教师的专业评价

1. 📸 **上传作品**
   - 进入课程，找到"模块三：AI点评作品"
   - 点击"上传作品"按钮

2. 🤖 **获得AI点评**
   - AI老师会根据教师设定的标准进行点评
   - 评价内容包含：亮点、建议、总体评价

3. 🔊 **可选：播放语音**
   - 点击"生成语音"按钮
   - AI老师会用语音讲述点评内容

## 常见问题

### Q1: 如何快速恢复为默认模板？

A: 不需要做任何操作。如果你觉得当前模板不合适，直接修改为默认值即可。

**各课程的默认模板**

| 课程名 | 维度1 | 维度2 | 维度3 |
|--------|------|------|------|
| 发型设计 | 线条精准度与蓬松感 | 层次感与空间表现 | 风格特征的表现力 |
| 脸型绘制 | 脸型比例的准确性 | 脸部轮廓的立体感 | 脸型特征的个性体现 |
| 五官刻画 | 五官位置关系的准确性 | 眼睛神韵与情感表达 | 五官整体协调度 |
| 肤色表现 | 色彩冷暖搭配的合理性 | 明暗层次与光影表现 | 肤色质感的逼真度 |
| 体型塑造 | 人体比例结构的科学性 | 肢体姿态的自然度 | 身体动态的灵活性 |

### Q2: 我是学生，为什么看不到修改按钮？

A: 修改模板的权限只有教师有。如果你想建议新的评估维度，请告诉你的教师。

### Q3: 修改模板后，之前的点评内容会改变吗？

A: 不会。之前的点评内容保持不变。只有之后的新点评才会使用新的模板。

### Q4: 可以为不同学生设置不同的模板吗？

A: 目前暂不支持。所有学生使用相同的模板。该功能可能在未来版本中添加。

### Q5: 如何确保我的模板改动已保存？

A: 
- 看到"✅ 模板保存成功"的消息
- 关闭弹窗后，再次点击"修改模板"，确认你的内容还在

## 模板设计建议

### ✅ 好的模板示例

```
鼓励语：你对构图的理解很有深度！

评价维度1：人物与场景的视觉层次 ← 具体、可测量
评价维度2：构图布局的合理性      ← 与教学目标一致
评价维度3：画面信息的完整表达    ← 易于学生理解
```

### ❌ 不推荐的模板

```
鼓励语：很好

评价维度1：好不好     ← 太宽泛，AI难以理解
评价维度2：棒不棒     ← 缺乏具体性
评价维度3：优秀吗     ← 不是陈述句
```

### 💡 模板设计原则

1. **清晰具体**
   - 用具体词语代替抽象词语
   - 好：「线条精准度」vs 坏：「好看不好看」

2. **可测量性**
   - 评价维度应该可以通过观察作品来判断
   - 好：「色彩冷暖搭配」vs 坏：「整体感觉」

3. **教学目标对齐**
   - 反映该课程的学习重点
   - 发型课重点：线条、层次、风格
   - 构图课重点：布局、层次、焦点

4. **励志性**
   - 鼓励语要能激励学生继续创作
   - 好：「你对细节的观察很敏锐」
   - 坏：「作品有问题」

## 技术细节（供开发者）

### 数据流

```
教师编辑 → 前端提交 → 后端API保存 → 数据库更新
                                ↓
                        学生上传作品
                                ↓
                        后端自动加载教师模板
                                ↓
                        Vision分析 + 模板点评
                                ↓
                        学生收到AI点评
```

### API调用

```javascript
// 获取模板
GET /api/formal-lesson/lesson-template?lesson_key=formal_hairstyle

// 保存模板  
POST /api/formal-lesson/lesson-template
{
  "lesson_key": "formal_hairstyle",
  "encouragement": "...",
  "aspects": ["...", "...", "..."]
}

// 获取点评（自动使用教师模板）
POST /api/formal-lesson/artwork-feedback
```

### 数据库字段

```sql
-- users 表
feedback_templates: JSON
-- 存储格式：
{
  "formal_hairstyle": {
    "encouragement": "...",
    "aspects": ["...", "...", "..."]
  },
  "formal_face": {...},
  ...
}
```

## 故障排除

### 问题：保存模板后没有看到成功消息

**解决**：
1. 检查网络连接
2. 打开浏览器开发者工具（F12）检查错误
3. 查看浏览器控制台是否有错误信息

### 问题：修改按钮不显示

**解决**：
1. 确认你的账号角色是"教师"
2. 清除浏览器缓存后重新加载页面
3. 检查你是否有该课程的教学权限

### 问题：学生收到的评价没有改变

**解决**：
1. 确保你已点击"保存修改"
2. 让学生重新上传作品（不要使用已有的图片）
3. 确保学生属于你的班级
