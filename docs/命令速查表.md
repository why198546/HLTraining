# 🎨 无限画布命令速查表

## 快速启动

```
输入 / → 选择命令 → 开始创作
```

---

## 🎯 四大命令模式

### 1️⃣ 生成模式 🎨

**激活：** `/生成` 或 `/` → 选择"生成"

**用途：** 生成单张图片

**格式：**
```
描述你想要的图片
```

**示例：**
```
可爱的卡通熊猫
春天的樱花树
水彩风格的山水画
```

---

### 2️⃣ 多图模式 🖼️

**激活：** `/多图` 或 `/` → 选择"多图"

**用途：** 批量生成多张图片

**格式：**
```
数量 + 描述
```

**示例：**
```
3张 熊猫          ← 最简洁
生成5个风景        ← 带动词
风景画 4个         ← 描述在前
画二张中国风建筑   ← 中文数字
```

**数量范围：** 2-10张

---

### 3️⃣ 对话模式 💬

**激活：** `/对话` 或 `/` → 选择"对话"

**用途：** 与AI聊天交流

**格式：**
```
问题或讨论内容
```

**示例：**
```
怎么画好一只猫？
有什么创作建议？
如何使用这个工具？
```

---

### 4️⃣ 修改模式 ✨

**激活：** `/修改` 或 `/` → 选择"修改"

**用途：** 修改选中的图片

**前置条件：** 必须先选中一张图片（点击图片）

**格式：**
```
修改指令
```

**示例：**
```
换成夜晚场景
改成水彩风格
加上一只小鸟
```

**支持格式：**
- `画3张xxx`
- `生成5个yyy`
- `画xxx、yyy、zzz`
- `画xxx和yyy`

## ⚠️ 常见问题

### Q: 命令菜单没出现？
**A:** 确保输入的是英文斜杠 `/`

### Q: 多图模式没反应？
**A:** 检查格式，必须包含数量和描述

### Q: 修改模式不能用？
**A:** 先点击画布上的图片选中它

### Q: 生成太慢？
**A:** 多图模式2-3张最佳，避免一次生成太多
