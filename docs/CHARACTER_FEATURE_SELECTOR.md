# 人物特征选择器功能文档

## 功能概述
在"松果课堂-人物课"中新增了交互式特征选择器，让学生可以通过点击按钮快速构建人物描述，实现双向同步。

## 功能特点

### 1. 快速特征选择
- **10大特征类别**：性别、体型、头发长度、头发类型、皮肤、眼睛、鼻子、嘴巴、嘴唇、耳朵
- **即点即用**：点击选项自动添加到原始输入框
- **视觉反馈**：选中的特征会高亮显示

### 2. 双向同步机制

#### 选项 → 文本
- 点击特征按钮，自动将关键词添加到原始输入框
- 智能拼接：自动处理标点符号，避免重复添加
- 同组互斥：每个特征类别只能选择一个选项（如"男孩"和"女孩"互斥）

#### 文本 → 选项
- 手动输入或语音输入文本后，自动检测并高亮相关特征
- 实时分析：输入框内容变化时即时更新特征选择器状态
- 关键词匹配：基于后端特征检测系统的关键词列表

## 使用流程

### 方式一：特征选择器输入
1. 打开"松果课堂 - 人物课"
2. 在"🎨 快速特征选择"区域点击想要的特征
3. 选中的特征自动添加到"📝 原始输入"框
4. 点击✨按钮进行AI优化
5. 点击"生成图片"按钮

### 方式二：手工/语音输入
1. 直接在"📝 原始输入"框中手工输入或语音输入描述
2. 输入包含特征关键词时，上方的特征按钮会自动点亮
3. 可以补充点击其他特征按钮
4. 点击✨按钮进行AI优化
5. 点击"生成图片"按钮

### 方式三：混合使用
1. 先点击几个特征按钮
2. 再用语音或手工补充其他描述
3. 系统会同步更新特征选择器状态
4. 继续优化和生成

- 前端高亮检测准确
- 后端图片生成智能变化
- 两者逻辑统一
