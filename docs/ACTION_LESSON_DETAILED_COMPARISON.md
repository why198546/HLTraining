## 🕐 课堂时间分配参考

### 方案 1：绘图板

```
课堂总时长：45-60 分钟

准备阶段 (5分钟)
├─ 介绍工具界面
├─ 演示一个简单火柴人的绘制
└─ 展示预设动作

创作阶段 (20-25分钟)
├─ 学生自由选择：自己画或用预设
├─ 教师巡视指导
└─ 鼓励学生尝试不同动作

优化阶段 (8-10分钟)
├─ 选择动作关键词
├─ 查看提示词生成
└─ 可选：编辑提示词

生成和欣赏 (8-10分钟)
├─ 点击"生成图片"
├─ 查看 AI 生成的结果
└─ 互相分享和讨论

总结反思 (5分钟)
├─ 讨论：AI 怎样理解你的图？
├─ 分享最喜欢的作品
└─ 展望下一课
```

### 方案 2：拖拽编辑

```
课堂总时长：45-60 分钟

准备阶段 (5分钟)
├─ 介绍火柴人和拖拽机制
├─ 演示一个预设姿势
└─ 讲解角度的含义

参数调整阶段 (15-20分钟)
├─ 学生尝试拖拽各个部位
├─ 观察实时角度变化
├─ 试用 6 个预设姿势
└─ 尝试随机生成

手势选择阶段 (8-10分钟)
├─ 讨论：你的姿势像什么动作？
├─ 选择对应的手势选项
└─ 查看提示词自动生成

生成和对比 (8-10分钟)
├─ 点击"生成图片"
├─ 查看不同参数组合的效果
└─ 比较：哪个角度组合最自然？

深化思考 (5分钟)
├─ 讨论：参数如何影响效果？
├─ 反思：编程的参数化思维
└─ 展示优秀作品
```

## 💡 教师备课建议

### 准备工作

```
✅ 方案1（绘图板）准备
   □ 提前体验一遍，熟悉工具
   □ 准备 2-3 个绘画示例（好的/一般的）
   □ 准备讨论题：如何用最少笔画表现？
   □ 设想可能遇到的问题

✅ 方案2（拖拽编辑）准备
   □ 提前体验一遍，理解角度机制
   □ 计算几个动作的角度组合
   □ 准备讨论题：参数如何影响视觉？
   □ 想好如何讲解旋转中心概念

✅ 通用准备
   □ 检查 API 连接（图片生成）
   □ 准备参考示例图
   □ 了解本班学生的兴趣倾向
   □ 思考如何分组或个性化指导
```

## 🎓 学生学习成果示例

### 方案 1（绘图板）的学生可能说：
```
"我用画笔画了一个跑步的火柴人，
 AI 把它理解成'一个小朋友在跑步'，
 最后生成了一个看起来真的在跑的卡通小孩！
 
 我发现如果画得清楚，AI 就能理解得更准确。"
```

### 方案 2（拖拽编辑）的学生可能说：
```
"我发现拖拽左臂到 -30 度，右臂到 30 度，
 两条腿分别是 -45 和 45 度的时候，
 火柴人看起来最像在跑步。
 
 这就像编程里的变量，改变一个数值就改变结果！"
```
