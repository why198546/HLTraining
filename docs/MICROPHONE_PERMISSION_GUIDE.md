# 🎤 麦克风权限设置指南

## Safari浏览器

### 方法一：首次使用时选择"允许"（推荐）

1. 点击麦克风按钮 🎤
2. 浏览器弹出权限请求时，**点击"Allow"（允许）**
3. ✅ 系统会记住您的选择，下次访问自动允许

### 方法二：在Safari设置中手动授权

如果您之前点击了"拒绝"，可以通过以下步骤重新授权：

**在Mac上：**
1. 打开 **Safari浏览器**
2. 点击菜单栏 **Safari** → **设置**
3. 选择 **网站** 标签
4. 在左侧找到 **麦克风**
5. 找到 `localhost`（或您的网站地址）
6. 将权限设置为 **允许**

**快捷方式：**
- 点击地址栏左侧的网站设置图标
- 在弹出的菜单中找到"麦克风"
- 选择"允许"

## Chrome浏览器

### 方法一：首次使用时选择"允许"

1. 点击麦克风按钮 🎤
2. 浏览器地址栏下方弹出权限请求
3. 点击 **"允许"**
4. ✅ Chrome会永久记住此设置

### 方法二：手动设置网站权限

1. 点击地址栏左侧的 🔒 或 🛈 图标
2. 找到"麦克风"选项
3. 选择"允许"
4. 刷新页面

**或通过Chrome设置：**
1. 打开 Chrome 设置
2. 隐私和安全 → 网站设置
3. 权限 → 麦克风
4. 在"允许"列表中添加您的网站

## Edge浏览器

1. 点击地址栏右侧的 🔒 图标
2. 选择"此网站的权限"
3. 找到"麦克风"
4. 选择"允许"
5. 关闭设置，刷新页面

## 常见问题

### Q: 为什么每次都要授权？

**A**: 可能的原因：
1. 您之前选择了"Never for This Website"（此网站永不允许）
2. 浏览器的隐私模式（无痕浏览）不会保存权限设置
3. 浏览器清除了Cookie和网站数据

**解决方法**：
- 确保不在隐私/无痕模式下浏览
- 检查浏览器设置，将网站添加到麦克风允许列表
- 不要频繁清除浏览器数据

### Q: 我不小心点了"拒绝"怎么办？

**A**: 按照上面的"方法二"重新授权即可。

### Q: 语音功能不可用？

**A**: 检查：
1. 麦克风是否正常工作（在系统设置中测试）
2. 浏览器是否支持语音识别（推荐Chrome/Safari）
3. 是否授予了麦克风权限
4. 网络连接是否正常

## 系统级麦克风权限（Mac）

如果浏览器无法访问麦克风，检查系统设置：

1. 打开 **系统设置** → **隐私与安全性**
2. 选择 **麦克风**
3. 确保您的浏览器（Safari/Chrome/Edge）已勾选
4. 如果没有，点击 **+** 添加浏览器

## 推荐设置

✅ **最佳体验**：
- 使用 Chrome 或 Safari 最新版本
- 首次使用时选择"允许"
- 保持正常浏览模式（非隐私模式）

⚠️ **注意事项**：
- 隐私模式不会保存权限设置
- 清除浏览器数据会删除权限记录
- 某些浏览器扩展可能阻止麦克风访问

## 安全提示

🔒 我们的网站：
- 仅在您点击麦克风按钮时访问麦克风
- 不会在后台录音
- 语音数据仅用于转换成文字
- 不会保存或上传语音录音
- 所有处理都是安全和私密的

如果您对隐私有任何疑问，可以随时在浏览器设置中撤销麦克风权限。
