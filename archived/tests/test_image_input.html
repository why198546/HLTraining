🧪 测试步骤

测试1: 菜单功能

1. 访问 http://127.0.0.1:8088/create/image
2. 点击输入框右下角的"+"按钮
3. 应显示菜单：上传图片、拍照
4. 点击页面其他地方，菜单应关闭

实现
测试2: 文件上传

1. 点击"+"→ "上传图片"
2. 选择一个图片文件
3. 图片应显示在预览区域
4. 显示成功提示

实现
测试3: 摄像头拍照

1. 在移动设备上点击"+"→ "拍照"
2. 应调用系统相机
3. 拍照后图片显示在预览区域

实现

💡 桌面浏览器会打开文件选择（因为没有相机）

测试4: 拖拽上传

1. 从桌面拖动一个图片文件
2. 移到输入框区域（显示虚线边框和提示）
3. 松开鼠标
4. 图片应显示在预览区域

实现
测试5: 粘贴图片

1. 从其他应用复制一张图片（如截图、浏览器图片）
2. 在页面按 Ctrl+V (或 Cmd+V)
3. 图片应显示在预览区域
4. 显示"图片已粘贴"提示

实现
测试6: 粘贴图片链接

1. 复制一个图片URL（如：https://example.com/image.jpg）
2. 在输入框粘贴
3. 显示"正在加载图片..."
4. 加载成功后显示图片预览
5. 显示"图片链接已加载"提示

实现

💡 使用提示

  • 在桌面浏览器中，可以从文件夹拖拽图片到页面
  • 使用截图工具（如Windows的Snipping Tool）后直接粘贴
  • 从浏览器中右键复制图片地址，然后粘贴URL
  • 在iPad上，可以从照片库拖拽图片到Safari浏览器
  • 在手机上，点击"拍照"可以选择前置或后置摄像头
