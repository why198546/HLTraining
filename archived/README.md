# 归档文件说明

此目录存放已废弃或一次性使用的文件，避免污染主项目目录和干扰AI Agent。

## 目录结构

### scripts/
存放一次性使用的脚本和测试文件：
- `test_*.py` - 各种测试脚本（API测试、数据库测试等）
- `create_*_table.py` - 数据库表创建脚本（已执行完毕）
- 其他管理和调试脚本

### docs/
存放历史功能文档和完成报告：
- API重构文档
- 功能集成指南
- 系统升级记录
- 测试报告

### templates/
存放废弃的模板文件：
- `components/auth_header.html` - 已被header.html替代的旧导航组件

## 注意事项

⚠️ **归档文件不应该被再次使用**
- 这些文件仅作为历史记录保留
- 如需类似功能，请基于当前代码重新实现
- AI Agent在生成代码时应避免引用归档文件

## 归档原则

符合以下条件的文件应该归档：
1. 一次性使用的脚本（数据库迁移、初始化等）
2. 已被替代的旧版本代码
3. 已完成的项目文档和报告
4. 临时测试脚本
5. 废弃的组件或模块

## 清理建议

可以定期（如每季度）审查归档文件，彻底删除超过6个月且确认无用的文件。
